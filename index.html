OPEN WEB STANDARDS

The technologies behind the website

HTML

Create the structure

  • Defines the structure and meaning of the content
  • Organizes content into elements
  • Provides the semantic foundation of a web page

CSS

Style the website

  • Controls the visual appearance and layout
  • Applies styles to web page elements
  • Makes web pages responsive to different screen sizes

JavaScript

Add interactivity

  • Adds behavior and interaction
  • Responds to user actions
  • Dynamically changes the content and appearance
